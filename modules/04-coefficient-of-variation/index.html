Coefficient of variation

Comparing relative variability in clinical laboratory examples.

Created by: Mahdi Akbarzadeh
Visual explanation
R activity

Learning goals

  • Define coefficient of variation as SD divided by mean times 100.
  • Explain why CV is unitless and expresses relative variability.
  • Compare raw SD and CV in a laboratory analyzer example.
  • Avoid misleading conclusions when variables are on different scales.

Teaching notes

  • Raw SD is scale-dependent.
  • CV is useful when comparing relative variability across different scales.
  • A smaller raw SD does not always mean better precision.
  • CV is useful in laboratory science, quality control, and biomedical measurement.
Common mistake: Assuming that the analyzer with the smaller raw SD is always more precise.

R activity

The activity creates two laboratory analyzer examples, calculates mean, SD, and CV, and compares raw SD with CV.

The dataset is created inside the R script. Students can run the file directly without opening a separate data file.

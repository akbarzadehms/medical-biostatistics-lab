Module 02

Variability, variance, and standard deviation

Why the mean alone is not enough to describe medical data.

Created by: Mahdi Akbarzadeh
Visual explanation
R activity

Learning goals

  • Explain why a measure of center should be accompanied by a measure of spread.
  • Compare range, variance, and standard deviation.
  • Interpret standard deviation as spread around the mean in the original unit.
  • Use a dot plot to compare two groups with different variability.

Teaching notes

  • Two datasets may have similar centers but very different clinical implications.
  • Variance is based on squared deviations from the mean.
  • Standard deviation returns spread to the original unit of measurement.
  • Spread affects how representative the mean appears.
Common mistake: Comparing groups using only their means and ignoring the spread of the data.

R activity

The activity defines two small score datasets and compares mean, range, variance, and standard deviation visually.

The dataset is created inside the R script. Students can run the file directly without opening a separate data file.

Teaching notes

A Z-score standardizes a raw value by subtracting the reference mean and dividing by the reference standard deviation. The result tells us how many standard deviations the value is from the mean.

A positive Z-score means the value is above the mean. A negative Z-score means the value is below the mean. The magnitude of the Z-score shows how far the value is from the reference mean.

Under a normal model, a Z-score can be converted into a percentile. A percentile describes relative position in the reference distribution. It should not be interpreted as a percentage of health, correctness, or clinical success.

Visual explanation

A raw value such as birth weight or an exam score is difficult to interpret alone. The same raw value may be ordinary in one reference group and unusual in another. Z-scores solve this problem by placing the value on a common standardized scale.

Common mistake

A common mistake is to compare raw values across different distributions. Standardized comparison requires the reference distribution.

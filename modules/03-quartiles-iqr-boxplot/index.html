Quartiles, IQR, boxplots, and outliers

Interpreting the middle 50% of a dataset and detecting outliers with fences.

Created by: Mahdi Akbarzadeh
Visual explanation
R activity

Learning goals

  • Define Q1, median, Q3, and IQR.
  • Explain why IQR represents the middle 50% of the data.
  • Compute lower and upper fences using the 1.5 × IQR rule.
  • Interpret a boxplot as a compact visual summary.

Teaching notes

  • Q1 and Q3 are not outlier thresholds by themselves.
  • IQR is more robust to extreme values than range.
  • The 1.5 × IQR rule is a screening rule.
  • Boxplots are especially useful for skewed variables such as hospital stay.
Common mistake: Calling every value above Q3 or below Q1 an outlier.

R activity

The activity simulates hospital-stay data, computes quartiles, IQR, fences, and marks outliers on a boxplot.

The dataset is created inside the R script. Students can run the file directly without opening a separate data file.

# Teaching Map

Created by: Mahdi Akbarzadeh

## Teaching sequence

```text
Clinical question → Statistical concept → Visual explanation → R activity → Student interpretation → Common mistake
```

## Initial modules

| Module | Visual output | R activity | Common mistake |
|---|---|---|---|
| Mean vs Median | Annotated histogram | Simulated BP with an extreme value | Mean always represents the typical patient |
| Variability and SD | Dot plot | Two small datasets with different spread | Mean alone is enough |
| IQR and Boxplot | Annotated boxplot | Simulated hospital stay | Every value above Q3 is an outlier |
| CV | Bar chart comparison | Synthetic laboratory analyzers | Smaller raw SD always means better precision |

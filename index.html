Course design

The material is organized around a simple teaching sequence: start with a clinical question, introduce the statistical idea, examine the visual pattern, run a short R activity, and then write an interpretation in medical language.

Core sequence: Clinical question Statistical concept Visual explanation R activity Interpretation

How students use it

  • Read the short teaching page for each section.
  • Run the corresponding R activity.
  • Open the figure saved by the script.
  • Answer the interpretation questions.
  • Check the common mistake highlighted in the section.
